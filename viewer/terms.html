Agent Office 서비스 약관

Agent Office는 연구 프로젝트 참여자를 위한 비공개 도구이며, 프로젝트 저장소의 협업자로 초대된 사람만 사용할 수 있습니다.

이용

  • 자료실에 올리는 파일은 프로젝트 소유자의 Google Drive 폴더에 저장되며, 프로젝트 참여자에게 공유될 수 있습니다. 공유해서는 안 되는 자료(개인정보·계약상 비밀 등)는 올리지 마세요.
  • 회의 글과 댓글은 GitHub Discussions에 본인 GitHub 계정 이름으로 남습니다.

책임

이 도구는 있는 그대로 제공되며, 저장된 자료의 백업·보존은 각 프로젝트 소유자의 책임입니다. 운영자는 사전 통지 없이 기능을 바꾸거나 중단할 수 있습니다.
